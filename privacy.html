プライバシーポリシー

発効日・最終更新日　2026年11月19日

このポリシーは、SHIHMING CHIU（開発者）が提供する「応用情報技術者試験 コツコツ過去問」と、このサポートサイトに適用されます。

回答や自己評価はお使いの端末に保存されます。
お問い合わせの際は、利用者がメールで送った内容や添付ファイルを開発者が受け取ります。サイトの閲覧時には GitHub Pages が通信情報を取り扱います。

学習データ消去とバックアップお問い合わせ情報外部サービス

端末内の学習データ

練習の再開、復習、学習結果の表示のため、次の情報を App の保存領域に記録します。

  • 科目Aで選んだ回答、選択肢の順序、正誤、回答時の問題と解説。
  • 科目Bの記述回答と下書き、回答時の設問と正解例、自己評価、その修正履歴。旧版で保存された評価がある場合は、その記録も引き継ぎます。
  • 練習の進み具合、実施日時、日別集計に使う日付やタイムゾーン、ブックマーク、学習目標、出題条件などの設定。

回答、自己評価、学習履歴を開発者や AI サービスへ自動送信する機能はありません。日別集計には端末の日付とタイムゾーンを使い、位置情報は取得しません。アカウント登録は不要で、広告、アクセス解析、広告目的のトラッキングは行いません。

学習データの保存・消去とバックアップ

記録は利用者が消去するまで端末に保存されます。設定の「学習データをすべて消去」から「すべて消去する」を選ぶと、両科目の回答履歴、下書き、自己評価と修正履歴、途中の練習、ブックマークが消去され、学習目標や出題条件は初期状態に戻ります。内蔵の問題集は引き続き利用できます。

端末の設定によっては、学習データが iCloud またはコンピュータのバックアップに含まれます。App でデータを消去しても、既存のバックアップは別に管理されます。App 独自のクラウド同期はなく、開発者が端末の記録を遠隔で閲覧、削除、復元することはできません。

お問い合わせ情報の利用・保管・削除

利用者がメールを送ると、開発者はメールアドレス、表示名、本文、ご自身で添付した画像などを受け取ります。返信、不具合や問題内容の調査、必要な追加連絡のために使用します。

対応やその後の確認に必要な間は保管し、不要になった情報は定期的な見直しの際に削除します。お問い合わせ情報の確認・訂正・削除をご希望の場合は、対象のメールが分かる情報を添えて support669796@gmail.com へご連絡ください。

メールの受信・管理には Gmail を利用します。メールサービスでの取り扱いは、Google プライバシーポリシーをご覧ください。

出典リンクとサポートサイト

App から原題などの出典を開くと、外部サイトへ移動します。リンクに利用者の回答や学習履歴は含めていません。アクセス先では IP アドレスなどの通信情報が扱われる場合があります。

このサイトは GitHub Pages で公開しています。GitHub はセキュリティのために訪問者の IP アドレスを記録・保存します。開発者はこのサイトにアクセス解析、広告、トラッキング用の Cookie やスクリプトを設けていません。
